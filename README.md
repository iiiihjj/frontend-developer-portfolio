# Frontend Developer Portfolio

## About the Project

This is my personal portfolio website, developed to showcase my frontend development skills, projects, and professional background. The website provides an overview of my experience, technical skills, and interest in building responsive and user-friendly web interfaces.

## Features

- Responsive design for desktop, tablet, and mobile devices
- Navigation bar with smooth scrolling
- Introduction and About Me sections
- Technical skills section
- Project cards to showcase my work
- Profile photo in the hero section
- Contact form with email application integration
- Mobile navigation menu using JavaScript
- Dynamic copyright year in the footer

## Technologies Used

- HTML5 — website structure
- CSS3 — styling, layouts, and responsive design
- JavaScript — interactive functionality

## Projects Showcased

### 1. Weather App
A weather application that retrieves weather information for a searched city using a weather API.

### 2. Drag-and-Drop File Uploader
An image uploader featuring drag-and-drop functionality, image preview, file type validation, and a simulated progress bar.

### 3. Multi-Step Form
A form interface with step-by-step navigation, required-field validation, a progress indicator, and a final summary.
## How to Run the Project

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.
4. Explore the different sections of the portfolio.
